# 图片路径存储优化说明

## 概述

优化了图片和视频路径的存储方式：
- **旧方式**：存储完整URL（如 `https://192.168.1.20:8090/profile/caseapp/20260102/xxx.jpg`）
- **新方式**：存储相对路径（如 `20260102/xxx.jpg`），显示时自动拼接

## 优势

1. **节省存储空间**：相对路径更短
2. **易于迁移**：更换服务器地址时无需修改数据库
3. **支持多环境**：开发、测试、生产环境可配置不同的URL前缀

## 实施步骤

### 步骤1：执行数据库迁移

**重要：执行前请先备份数据库！**

```bash
# 备份数据库
mysqldump -u root -p caseapp_db > backup_before_migration_$(date +%Y%m%d).sql
```

执行迁移脚本：
```bash
mysql -u root -p caseapp_db < scripts/migrate_image_paths.sql
```

或者在数据库管理工具中执行 `scripts/migrate_image_paths.sql`

### 步骤2：配置URL前缀

修改 `src/main/resources/application.yml`：

```yaml
ruoyi:
  # 图片/视频访问URL前缀
  profile-url: http://192.168.1.20:8090  # 修改为实际的服务器地址
```

**注意事项：**
- 根据实际环境修改域名和端口
- 开发环境：`http://localhost:8090`
- 测试环境：`http://test-server:8090`
- 生产环境：`https://prod-server.com`
- **不要在末尾添加 `/`**

### 步骤3：重新编译运行

```bash
mvn clean package
# 重启应用
```

## 技术实现

### 1. 工具类 `ImageUrlUtil`

位置：`com.ruoyi.common.utils.ImageUrlUtil`

主要方法：
- `toRelativePath(String fullUrl)`：完整URL → 相对路径
- `toFullUrl(String relativePath)`：相对路径 → 完整URL

### 2. 实体类自动转换

修改了以下实体类的getter/setter方法：

**AppTrack（轨迹表）**
- `pstp`：拍摄图片路径
- `spdz`：视频地址

**AppTrackScreenshot（截图表）**
- `screenshotUrl`：截图URL

转换逻辑：
- **set方法**：接收任何格式（完整URL或相对路径），自动转换为相对路径存储
- **get方法**：返回完整URL供前端使用

### 3. 数据流程

```
前端/API提交数据
    ↓
实体类 setter（自动提取相对路径）
    ↓
数据库存储（相对路径）
    ↓
数据库查询
    ↓
实体类 getter（自动拼接完整URL）
    ↓
前端/API接收（完整URL）
```

## 兼容性

### 向后兼容

- ✅ 已有的完整URL数据：通过迁移脚本转换为相对路径
- ✅ 新提交的数据：
  - 如果是完整URL，自动提取相对路径
  - 如果是相对路径，直接存储
- ✅ 前端代码：无需修改，仍然接收和显示完整URL

### 混合数据处理

即使数据库中同时存在新旧格式的数据，系统也能正常工作：
- 旧数据（完整URL）：getter会直接返回（因为已经是完整URL）
- 新数据（相对路径）：getter会拼接前缀返回完整URL

## 常见问题

### Q1: 迁移后图片不显示

**原因**：`application.yml` 中的 `profile-url` 配置不正确

**解决**：
1. 检查配置是否匹配实际的服务器地址和端口
2. 确保末尾没有 `/`
3. 重启应用

### Q2: 部分图片显示，部分不显示

**原因**：数据库中存在格式不一致的数据

**解决**：
1. 重新执行迁移脚本
2. 检查验证查询结果

### Q3: 导出功能中的图片路径问题

**原因**：导出功能中需要使用原始的相对路径（不拼接URL）

**解决**：
使用 `getRaw` 方法获取原始路径：
```java
String relativePath = track.getPstpRaw();  // 获取相对路径
```

## 回滚方案

如果需要回滚到旧的存储方式：

```sql
-- 将相对路径转换回完整URL
UPDATE app_track
SET pstp = CONCAT('http://192.168.1.20:8090/profile/caseapp/', pstp)
WHERE pstp NOT LIKE 'http%' AND pstp IS NOT NULL;

UPDATE app_track_screenshot
SET screenshot_url = CONCAT('http://192.168.1.20:8090/profile/caseapp/', screenshot_url)
WHERE screenshot_url NOT LIKE 'http%' AND screenshot_url IS NOT NULL;
```

然后注释掉实体类中的自动转换代码。
